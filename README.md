## Опис предметної області

Проєкт моделює інтернет-магазин електроніки та аксесуарів «TechNest», у якому покупці можуть переглядати каталог товарів, згрупованих за категоріями (смартфони, ноутбуки, навушники тощо). Кожен товар має назву, опис, ціну, бренд і кількість на складі, а покупець може додавати товари до кошика та змінювати їх кількість. На основі кошика оформлюється замовлення з адресою доставки, способом оплати та підсумковою вартістю з урахуванням знижок. Замовлення проходить статуси «Створено» → «Оплачено» → «Відправлено» → «Доставлено» (або «Скасовано»), а система контролює наявність товару та списує залишки на складі. Основні сутності: `Customer`, `Product`, `Category`, `Cart`, `CartItem`, `Order`, `OrderItem`, `Payment`.

